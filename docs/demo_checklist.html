Faculty demo — run sheet

Fraud campaign discovery from fragmented cross-institution evidence · ~10 minutes · campaigns 211, 241, 219

Start both servers

First, kill any backend left running from an earlier session. Artifacts are read once at startup and cached, and --reload restarts on code changes only — never on data. A stale process serves whatever it loaded whenever it started. 
# 0. clear port 8000
netstat -ano | findstr ":8000"      # note the PID in the last column
taskkill /PID <pid> /F
# Terminal 1 — backend
cd "C:\Users\ASUS\Downloads\FRAUD CAMPAIGN DETECTION PROJECT\backend"
python -m uvicorn app.main:app --reload --port 8000
# Terminal 2 — frontend
cd "C:\Users\ASUS\Downloads\FRAUD CAMPAIGN DETECTION PROJECT\frontend"
npm run dev

The frontend hard-defaults to http://localhost:8000, so the backend must be on port 8000. No .env is needed. App opens at http://localhost:5173.

The checklist

  1. http://localhost:8000/api/health

    Expect core_artifacts_available: true and nested_artifacts_dir: null. Then open the app — top-right chip must read “API ready” (green).

  2. /dataset

    Four cards: 5,078,345 transactions · 30,470 banks · 370 campaigns · 258 evaluable, with “3,209 transactions” and “152 can be fragmented”. The transactions-per-day chart shows a dashed Cutoff line with the tail after it shaded.

  3. /campaigns — filter, then clear

    25 rows by default. Set Pattern = BIPARTITE and Split = Test: removable chips appear and the live count drops. Clear both. rows open on click or Enter

  4. /campaigns/211 — the hub control

    A clean star with the hub account dead centre. Sidebar: Group Hub. Now set View = Target 25% visibility — the badge must stay 100% / bin 100% and show the note “never reassigned (hub-shaped or too small)”. This is the control-group proof: one bank always sees everything.

  5. /campaigns/241 — the structural blind spot

    Renders as 13 separate sender→receiver pairs, nothing joined to anything else. Sidebar: Evaluated Yes, Finished before cutoff Yes. Say: the matching rule needs 3 connected accounts; this campaign never connects more than 2, so the oracle misses it at both lookbacks — which is why oracle_reachable exists.

  6. Still on /campaigns/241 — step the View control

    Target 100 → 75 → 50 → 25 gives badges 100% (bin 100%) → 77% (bin 75%) → 46% (bin 50%) → 23% (bin Low). The whole dose–response in one control.

  7. Still on /campaigns/241 — bank’s-eye view

    Click bank tab I0, then one or two others. The header reads “This bank sees N of 13 transactions” and everything that bank cannot see fades out. At target 25% the best bank sees 3 of 13.

  8. /campaigns/219 — time replay

    Press Play: transactions appear one at a time, the counter runs “Showing k of 7”, and it stops at the end. Press Show all. Drag a node, then press Reset view. The deadline and cutoff marks sit on the time strip below.

  9. /visibility — the toy, then the real data

    Drag or click accounts between Bank I0 / I1 / I2 and watch the percentage recompute live. Then the real figures below: 152 fragmented · 219 landed in bin 100 · 2 unfragmentable. This is the only number on the whole site the frontend computes itself — and only for the scenario you just invented.

  10. /results, then /methodology, then the theme toggle

    Results: “Experiment results are not available yet”, the four conditions legend, five outlined figures, and no numbers at all. Methodology: 10 definition cards, each with its reason and values. Finally toggle light/dark (top right) while on campaign 241 and confirm the graph stays legible.

Say this, not that

Do not claim a CYCLE “looks like a ring”. The circle layout orders nodes alphabetically by account id, not by cycle traversal, so most edges cut across the middle as chords rather than following the rim (campaign 219: only 5 of 7 edges join circle-neighbours).

Say: “The layout is deterministic, so the same campaign draws identically every time — which is what we need for figures in the paper. The hub shapes in particular are unmistakable.”

Don’t say: “You can see at a glance that this is a ring.”

Lead the topology story with 211 (a genuinely perfect star) and 241 (13 visibly isolated pairs). Both carry the point without needing the ring.

If something goes wrong

SymptomCause and what to do
Chip reads “API unreachable”; pages say “Could not reach the API” Backend is down or not on port 8000. Restart Terminal 1. Pages recover on their own — no reload needed.
/api/health says artifacts are missing Read its hint field: it detects artifacts extracted one folder too deep. Fix the folder, then restart the server — artifacts are cached at startup.
A campaign page shows “Could not load this view” That id does not exist (valid ids are 0–369). Expected behaviour, not a crash.
The main panel is blank with the sidebar still showing A non-numeric id was typed in the URL, e.g. /campaigns/abc. Navigate to a real campaign. known, cosmetic
Results page says “Could not check for results” Backend unreachable. It is deliberately not claiming results are missing — only that it cannot tell.
